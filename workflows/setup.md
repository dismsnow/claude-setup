---
description: How to set up and start the Expo project
---

This project uses **Expo** and **Yarn**. To set up and run the local development server, follow these steps:

1. Install dependencies:
   // turbo
   ```bash
   yarn install
   ```

2. Start the Expo development server:
   // turbo
   ```bash
   yarn start
   ```

3. (Optional) Read the QR code to open it in Expo Go, or follow instructions to run on an iOS simulator / Android emulator.
